## Chrome Extension Flow
```
User clicks Cometeor icon
         ↓
popup.html loads + ui.ts runs
         ↓
User clicks "Login" button
         ↓
message-dispatcher routes to oauth2 handler
         ↓
token-store-refactored refreshes token (mutex guards concurrent calls)
         ↓
Content script injects into current tab
         ↓
Content script starts heartbeat (5-second pings to background)
         ↓
User types CSS selector or executes action
         ↓
validators.ts checks for XSS (12+ patterns)
         ↓
request-queue batches request (HIGH/NORMAL/LOW priority)
         ↓
circuit-breaker checks state (CLOSED=proceed, OPEN=fail fast, HALF_OPEN=test)
         ↓
Action executes: click/fill/scroll on DOM
         ↓
observability records latency, metrics, traces
         ↓
Response sent back to popup
         ↓
UI updates status (success/error)
```

## CRITICAL ARCHITECTURAL ISSUES (SESSION 2 AUDIT)

### Issue 1: WEBPACK ENTRY POINT MISMATCH (CRITICAL)
- **webpack.config.js**: entry point = `./src/background/index.ts`
- **Problem**: index.ts has **3 separate `chrome.runtime.onMessage.addListener()` calls**
- **Effect**: Race conditions, multiple handlers for same message type, unpredictable behavior
- **Solution**: Change webpack.config.js entry from `index.ts` → `index-refactored.ts` (MessageDispatcher)
- **Status**: NOT FIXED

### Issue 2: VERTEXCLIENT API MISMATCH (CRITICAL)
- **index.ts line 24**: calls `VertexClient.updateConfig(message.config)`
- **VertexClient**: only has `configure()` method, NOT `updateConfig()`
- **Effect**: Service worker crashes on CONFIG_UPDATED message
- **Solution**: Either (a) rename method to updateConfig, or (b) change index.ts to call configure()
- **Status**: NOT FIXED

### Issue 3: REQUESTQUEUE API MISMATCH (CRITICAL)
- **VertexClient.makeRequest()**: calls `this.queue.enqueue(async () => {...})`
- **RequestQueue.enqueue()**: expects `{ id: string, execute: () => Promise<T>, priority?: number }`
- **Effect**: Missing `id` field → RequestQueue crashes
- **Solution**: Wrap function with request ID: `this.queue.enqueue({ id: crypto.randomUUID(), execute: async () => {...} })`
- **Status**: NOT FIXED

### Issue 4: TOKEN MANAGEMENT INCONSISTENCY (MEDIUM)

- **Effect**: Mutex pattern (concurrent call protection) not being used
- **Solution**: Standardize on one implementation, update all imports
- **Status**: PARTIALLY FIXED (chrome.runtime.getURL() deferred)
